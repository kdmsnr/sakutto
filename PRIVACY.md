# Privacy policy

lmsakutto sends the text selected for translation to the LM Studio API on this computer at `127.0.0.1`. The extension does not send translation data to an external cloud service. LM Studio and its model are installed and managed separately.

The extension reads page content when translation is requested and stores settings in Chrome extension storage and cached translations in the extension’s IndexedDB. Chrome's site permissions control where the extension can access pages. Clearing the translation cache removes its saved translations; removing the extension removes its stored settings and cache.

The extension does not require a LAN-exposed LM Studio server. Other software or an LM Studio configuration outside the extension may have its own privacy behavior.

# プライバシーポリシー

lmsakutto は、翻訳対象のテキストを、このコンピューターの `127.0.0.1` で動作する LM Studio の API に送信します。拡張は翻訳データを外部のクラウドサービスへ送信しません。LM Studio とモデルは別途インストール・管理します。

拡張は翻訳の指示を受けたときにページの内容を読み、設定を Chrome の拡張機能ストレージに、翻訳キャッシュを拡張機能の IndexedDB に保存します。拡張がアクセスできるページは Chrome のサイト権限で制御できます。翻訳キャッシュを削除すると保存済みの訳文が消え、拡張機能を削除すると、保存済みの設定とキャッシュも削除されます。

LAN に公開した LM Studio サーバーは必要ありません。拡張以外のソフトウェアや LM Studio の設定によっては、それぞれ異なるプライバシー上の取り扱いがあります。
